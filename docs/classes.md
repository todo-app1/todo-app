# Классы системы ToDo

## Назначение каждого класса

*   **Task**: описывает одну конкретную задачу. Содержит название, дедлайн и флаг завершенности.
*   **TaskManager**: управляет коллекцией задач. Позволяет добавлять, удалять, искать и просматривать задачи.
*   **Storage**: абстрактный класс-хранилище. Определяет методы загрузки и сохранения списка задач.
*   **FileStorage**: сохраняет задачи в JSON-файл.
*   **MemoryStorage**: хранит задачи только в оперативной памяти (для тестов).
*   **ConsoleUI**: пользовательский интерфейс командной строки. Запускает приложение и взаимодействует с пользователем через консоль.

## Отношения между классами

*   **Ассоциация:** ConsoleUI связан с TaskManager. Интерфейс знает о менеджере и вызывает его методы.
*   **Агрегация:** TaskManager связан с множеством объектов Task. Менеджер содержит коллекцию задач, но сами объекты могут существовать отдельно.
*   **Зависимость:** TaskManager зависит от реализации Storage. Для сохранения данных он обращается к одному из подклассов Storage.
*   **Наследование:** FileStorage и MemoryStorage расширяют абстрактный класс Storage. Это позволяет легко менять способ хранения данных без изменения логики менеджера.
